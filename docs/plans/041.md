# Plan 041 - Staging Beverage Image Cache Provisioning

## Goal

Add a guarded GCP staging provisioning path for the beverage image cache used by
`BEVERAGE_IMAGE_CDN_BASE_URL`.

## Problem

Plans 039 and 040 made beverage images CDN-ready and exportable, but staging
operators still needed a safe way to create the recommendation-owned image cache
bucket, store the CDN base URL in Secret Manager, and pass that secret to the
seed promotion job.

Without this connection, the catalog metadata could be CDN-ready locally while
deployed seed promotion still used third-party source image URLs.

## Scope

- Add a dry-run-first GCP provisioning script for the staging beverage image
  cache bucket and CDN base URL secret.
- Require recommendation/beverage-owned names for the bucket and secret.
- Keep public read disabled by default.
- Grant the recommendation runtime service account access only to the CDN base
  URL secret.
- Allow the staging seed job to consume the CDN base URL secret through
  `BEVERAGE_IMAGE_CDN_BASE_URL`.
- Update deployment and release runbooks.

## Non-Goals

- No automatic Cloud CDN load balancer provisioning.
- No automatic image binary upload.
- No production bucket creation.
- No recommendation scoring changes.
- No DB schema changes.
- No Flutter changes.

## Acceptance Criteria

- [x] Provisioning script is dry-run by default.
- [x] Apply requires `RECOMMENDATION_IMAGE_CACHE_PROVISION_APPLY=1`.
- [x] Bucket and secret names are guarded as recommendation/beverage-owned.
- [x] Public read is opt-in through `RECOMMENDATION_IMAGE_CACHE_PUBLIC_READ=1`.
- [x] Seed job can opt into the CDN base URL secret.
- [x] Shell syntax checks pass.
- [x] Full release gate passes.

## Rollback

Unset `RECOMMENDATION_BEVERAGE_IMAGE_CDN_BASE_URL_SECRET` when running the seed
job to return to source image display URLs. If staging resources were created,
remove the image cache bucket and `recommendation-beverage-image-cdn-base-url-staging`
secret only after confirming no deployed catalog metadata points to that CDN
base URL.
