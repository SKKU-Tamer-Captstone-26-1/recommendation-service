# Plan 037 - Beverage Image Candidate Source Policy Gate

## Goal

Prevent unsafe beverage image rows from entering the canonical seed promotion
path.

This protects Flutter recommendation cards after direct product/cocktail images
were added in Plan 035.

## Problem

Image metadata is now app-visible. Even though the current rows use
source-checked Wikimedia Commons assets, a future data edit could accidentally
add:

```text
random search thumbnails
retailer images without license
HTTP URLs
direct images for unknown beverage candidates
category mismatches
duplicate direct images where lexical ordering silently picks a winner
```

That would be a production risk because Flutter displays `metadata.image_url`
directly.

## Scope

- Validate image candidates during `load_candidate_artifacts`.
- Allow only approved MVP image source types.
- Require HTTPS image/source/license URLs.
- Require explicit boolean `attribution_required`.
- Require known `beverage_candidate_id` for direct product/cocktail images.
- Require direct image category to match catalog candidate category.
- Reject duplicate category fallback images and duplicate direct images.
- Keep category fallback coverage for MVP seed categories.
- Add focused importer tests.
- Update image source policy docs.

## Non-Goals

- No network HEAD/GET checks.
- No binary image downloads.
- No official packshot scraping.
- No DB schema change.
- No recommendation scoring change.
- No Flutter change.

## Acceptance Criteria

- [x] Current image candidates pass importer validation.
- [x] Unsupported image `source_type` fails before promotion.
- [x] Unknown direct image `beverage_candidate_id` fails before promotion.
- [x] Direct image category mismatch fails before promotion.
- [x] Non-HTTPS image URL fails before promotion.
- [x] Focused tests pass.
- [x] Full release gate passes.

## Rollback

Rollback is code/test/documentation only. Revert the importer validation helpers
and tests. Existing canonical image metadata remains display-only and can still
be audited by the catalog audit.
