# Plan 039 - Beverage Image Cache URL Readiness

## Goal

Make beverage recommendation image metadata ready for production app display
without depending on third-party hotlinking.

## Problem

Plan 038 added an optional image URL smoke and revealed that Wikimedia direct
links can return rate-limit responses during repeated checks. The image
metadata is legally traceable and app-visible, but a production mobile app
should not depend on third-party image host behavior for every recommendation
card render.

## Scope

- Keep `metadata_json.image_url` as the Flutter display URL contract.
- Add deterministic image cache metadata to promoted beverage seed records:
  `original_image_url`, `cache_key`, `cache_policy`, and `display_url_source`.
- Add `BEVERAGE_IMAGE_CDN_BASE_URL` so staging/production seed promotion can
  rewrite display URLs to an ONTHEBLOCK-managed cache/CDN base.
- Preserve original licensed source image URLs and source/license pages for
  attribution and audit traceability.
- Extend catalog audit metrics to prove cache metadata coverage.
- Update Flutter/API/source-policy/release-gate documentation.

## Non-Goals

- No binary image download or upload in this repository.
- No Cloud Storage bucket creation.
- No Cloud CDN provisioning.
- No recommendation ranking, scoring, or vector changes.
- No DB schema change.
- No Flutter code change.

## Acceptance Criteria

- [x] Local seed promotion still produces valid source-checked display images.
- [x] Every active seed beverage has image cache metadata.
- [x] Setting `BEVERAGE_IMAGE_CDN_BASE_URL` rewrites display image URLs to a
  deterministic cache URL.
- [x] Original licensed image URLs remain available in metadata.
- [x] Non-HTTPS CDN base URLs are rejected before seed promotion.
- [x] Catalog audit reports `image_cache_metadata_coverage`.
- [x] Focused tests pass.
- [x] Full release gate passes.

## Rollback

Unset `BEVERAGE_IMAGE_CDN_BASE_URL` and re-run seed promotion to restore
licensed source image URLs as the display URLs. Code rollback is limited to the
importer cache metadata helpers, catalog audit cache checks, tests, and
documentation.
