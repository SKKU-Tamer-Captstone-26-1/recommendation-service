# Plan 047 - Map Route Distance Deployed Smoke

## Goal

Add deployed smoke evidence for the future map-service route distance API used by
venue, store, and outdoor recommendations.

The runtime route client from Plan 045 can call map-service, but production
readiness also needs a repeatable operator check that proves the deployed
map-service endpoint accepts the same request contract and returns a parseable
route estimate, or an explicit no-route response.

## Scope

- Add a `map_route` deployed smoke mode.
- Post the `map_route_distance_request_v1` contract to map-service.
- Parse the response with the same route-distance parser used by the runtime
  client.
- Support optional user bearer auth and private Cloud Run
  `x-serverless-authorization`.
- Accept `204` or `404` as no-route unless `MAP_ROUTE_SMOKE_EXPECT_ROUTE=true`.
- Document the required environment variables.

## Non-Goals

- No map-service database access.
- No route optimization in recommendation-service.
- No scoring formula change.
- No API/proto change for recommendation-service.
- No Flutter, gateway, chatbot, or LLM implementation.

## Environment

```text
MAP_ROUTE_SMOKE_BASE_URL=https://<map-service-url>
MAP_ROUTE_SMOKE_PATH=/internal/v1/recommendation/route-distance
MAP_ROUTE_SMOKE_PLACE_ID=<place-id>
MAP_ROUTE_SMOKE_ORIGIN_LAT=<lat>
MAP_ROUTE_SMOKE_ORIGIN_LNG=<lng>
MAP_ROUTE_SMOKE_DESTINATION_LAT=<lat>
MAP_ROUTE_SMOKE_DESTINATION_LNG=<lng>
MAP_ROUTE_SMOKE_EXPECT_ROUTE=true|false
MAP_ROUTE_SMOKE_SERVERLESS_AUTH_TOKEN=<google-id-token>
```

`MAP_SMOKE_BASE_URL` may be used instead of `MAP_ROUTE_SMOKE_BASE_URL`.

## Acceptance Criteria

- [x] `run_deployed_smokes(mode="all")` includes `map_route` and skips cleanly
  when env is missing.
- [x] `map_route` smoke posts the same contract as the runtime route client.
- [x] `map_route` smoke parses route distance, duration, complexity, and
  confidence.
- [x] `map_route` smoke preserves optional bearer auth and serverless auth
  metadata.
- [x] Missing route responses pass only when a route is not required.
- [x] Focused tests pass.
- [x] Full release gate passes.

## Rollback

Rollback is code/documentation only. Remove the `map_route` runner, CLI mode,
tests, and release-gate documentation. Runtime route distance wiring from Plan
045 remains independent.
