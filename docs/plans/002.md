# Production Beverage Recommendation Engine Slice

## 1. Goal

Implement the first production-grade recommendation slice for beverages.

The slice must:

- stage all current beverage candidate artifacts for review traceability
- promote only a fixed reviewed MVP seed subset into canonical tables
- generate deterministic beverage recommendations from PostgreSQL vectors
- expose authenticated beverage recommendation gRPC methods
- persist recommendation request, result, explanation, and interaction logs

## 2. Non-Goals

- Do not load all 120 candidates into canonical recommendation tables.
- Do not treat candidate KRW observations as live price truth.
- Do not implement venue recommendations yet.
- Do not write map/place, auth, or survey databases.
- Do not use Qdrant as a required ranking dependency.
- Do not use RAG or an LLM for ranking or explanation truth.

## 5. Proposed Change

Implementation readiness gates:

```text
service boundary | API contract | database contract | recommendation contract |
verification contract
```

The implementation promotes a fixed 24-beverage subset, two per category, into
canonical `beverage_items`, `flavor_profiles`, and `recommendation_vectors`.
All 120 candidates remain available in `recommendation_staging` for review.

## 6. Database Plan

Tables:

- `recommendation_staging.beverage_collection_runs`
- `recommendation_staging.beverage_catalog_candidates`
- `recommendation_staging.beverage_flavor_profile_candidates`
- `recommendation_staging.beverage_knowledge_candidates`
- `recommendation_staging.beverage_price_observation_candidates`
- `recommendation_staging.beverage_source_refs`
- `recommendation_staging.beverage_candidate_import_errors`

Indexes and constraints:

- unique run ID
- unique staging candidate/source IDs
- lookup indexes by category, beverage candidate, market/currency, and URL
- partial unique index on `recommendation_interactions.idempotency_key`

Lifecycle:

- staging rows are `needs_review` candidate evidence
- canonical promoted rows are active MVP seed rows
- Qdrant is not populated by this slice

Rollback:

- drop the additive staging schema
- drop the interaction idempotency index
- canonical seed rows can be disabled by setting `beverage_items.active = false`

## 7. API Plan

Public gRPC service:

```proto
service RecommendationService {
  rpc GetProfileStatus(GetProfileStatusRequest) returns (GetProfileStatusResponse);
  rpc GetBeverageRecommendations(GetBeverageRecommendationsRequest)
      returns (GetBeverageRecommendationsResponse);
  rpc RecordRecommendationEvent(RecordRecommendationEventRequest)
      returns (RecordRecommendationEventResponse);
}
```

Rules:

- identity comes from verified JWT metadata only
- request messages do not include `user_id` or `external_user_id`
- `BudgetMode` and recommendation event values are protobuf enums
- compact response details use `google.protobuf.Struct metadata`
- strict budget mode returns `FAILED_PRECONDITION`
- missing profile returns typed profile status with empty recommendations

## 10. Acceptance Criteria

- [ ] `recommendation_staging` exists after migration.
- [ ] all candidate artifacts can be staged idempotently.
- [ ] exactly 24 MVP beverages are promoted canonically.
- [ ] each promoted beverage has one flavor profile and one `taste_v1` vector.
- [ ] `GetBeverageRecommendations` ranks from PostgreSQL vectors.
- [ ] recommendation requests, results, and explanations are persisted.
- [ ] JWT identity is required for public gRPC methods.
- [ ] strict budget mode does not use candidate price observations.
- [ ] tests, lint, compile, and migration checks pass.

## 11. Risks

- Risk: candidate data still needs broader human review.
  Mitigation: promote only the fixed seed subset and keep all other rows staged.
- Risk: price observations may be mistaken for live offers.
  Mitigation: store no canonical seed price range and reject strict budget mode.
- Risk: survey-service contract is not finalized.
  Mitigation: implement only pure DTO mapping and leave polling integration out.
- Risk: Qdrant could become hidden source of truth.
  Mitigation: do not index Qdrant in this slice.
