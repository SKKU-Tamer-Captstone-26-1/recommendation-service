# Plan 044 - Live Beverage Flavor Direction Contract

## Goal

Expose a production-safe `flavor_direction` control on
`GetBeverageRecommendations` so chatbot/app follow-up requests like "더 달게",
"덜 피트하게", or "더 가볍게" remain recommendation-service-owned.

## Problem

Plan 043 proved offline readiness for directional follow-ups, but chatbot-service
still had no live API field it could use. Without a server-owned field, chatbot
would be tempted to filter or rerank beverage cards locally, which would violate
recommendation ownership and make results non-reproducible.

## Scope

- Add `BeverageFlavorDirection` enum to `recommendation.proto`.
- Add `flavor_direction = 7` to `GetBeverageRecommendationsRequest`.
- Update the committed Python dynamic protobuf descriptor.
- Map gRPC enum values to internal deterministic string controls.
- Add request-level beverage score adjustment using canonical beverage vectors.
- Preserve policy, direction, fit, adjustment, and dimension weights in model
  features.
- Store `flavor_direction` in request filters, request context, and result
  snapshot request controls.
- Add service and gRPC contract tests.
- Update API, Flutter handoff, recommendation logic, and Korean strategy docs.

## Non-Goals

- No stored taste profile mutation.
- No vector schema change.
- No DB schema or migration change.
- No chatbot-service implementation.
- No Flutter implementation.
- No LLM/RAG ranking.
- No price or venue live-data change.

## Supported Directions

```text
SWEETER
LESS_SWEET
SMOKIER
LESS_SMOKY
LIGHTER
RICHER
MORE_HERBAL_BITTER
BRIGHTER_FRUITY
```

## Acceptance Criteria

- [x] Proto request has `flavor_direction` and still has no client `user_id`.
- [x] Unknown flavor direction enum values are rejected.
- [x] A `SMOKIER` request can change the beverage rank deterministically.
- [x] Result metadata includes `flavor_direction_feature`.
- [x] Request/result logs preserve the flavor-direction control and policy.
- [x] Existing direction evaluation gate remains enabled.
- [x] Focused tests pass.
- [x] Full release gate passes.

## Rollback

Deploy the previous service revision or ignore `flavor_direction` in the gRPC
handler. Since this is additive and does not change stored profile vectors or DB
schema, rollback does not require data migration.
