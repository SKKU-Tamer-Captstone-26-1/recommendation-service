# Plan 026 - Category Evaluation Depth Gate

## Goal

Raise drink recommendation release confidence by requiring at least two offline
evaluation fixtures for every active beverage catalog category.

## Problem

Plan 025 added a gate that ensures every active category appears in evaluation
fixtures at least once. One fixture per category is useful, but still too thin
for production-quality drink recommendation work. A single fixture can pass
while another realistic profile in the same category is untested.

## Scope

- Add fixtures for thin-coverage categories:
  - `brandy_cognac`
  - `sake_shochu`
  - `tequila_mezcal`
  - `vodka`
- Raise release gate fixture count from 20 to 24.
- Raise release gate top-k hit-rate threshold from 0.85 to 0.95.
- Raise minimum fixtures per active category from 1 to 2.
- Keep evaluation based on active canonical catalog keys.

## Non-Goals

- No scoring weight change.
- No mapper change.
- No catalog import change.
- No model training.
- No map, gateway, Flutter, or chatbot implementation.

## Acceptance Criteria

- [x] evaluation fixture count is at least 24.
- [x] every active category has at least two fixtures.
- [x] `scoring_v3` top-k hit-rate remains at least 0.95.
- [x] negative violations remain zero.
- [x] release gate enforces the stronger thresholds.
- [ ] focused checks pass.
- [ ] full release gate passes.

## Rollback

Rollback is data/configuration only. Remove the four added fixtures and restore
the release gate thresholds to Plan 025 values.
