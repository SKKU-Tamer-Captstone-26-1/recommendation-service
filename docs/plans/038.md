# Plan 038 - Beverage Image URL Accessibility Smoke

## Goal

Add an optional smoke check that verifies app-visible beverage image URLs return
image responses before Flutter releases display them.

## Problem

Plans 035 and 037 made beverage image metadata production-shaped:

```text
image_url
source_url
license
attribution
display_policy
review_status
```

The deterministic release gate now proves metadata coverage and source policy.
It still does not prove that the third-party image host is reachable at release
time. This is the right default because the release gate must remain stable, but
operators need an explicit check before shipping image cards.

## Scope

- Add a service that extracts beverage image URL targets from seed records or
  active database beverages.
- Add a network smoke runner that checks status code and `image/*` content type.
- Use an explicit service User-Agent so third-party hosts can identify the smoke
  instead of seeing a generic HTTP client.
- De-duplicate repeated image URLs by default and support a request interval so
  shared category fallback images do not create unnecessary third-party traffic.
- Add a CLI tool for seed and database modes.
- Add tests with fake fetchers so no test depends on external network access.
- Document the smoke as optional release evidence.

## Non-Goals

- No binary image downloads or image storage.
- No image scraping.
- No new image candidates.
- No recommendation ranking, scoring, or vector changes.
- No DB schema changes.
- No Flutter implementation changes.
- No default release gate dependency on third-party hosts.

## Acceptance Criteria

- [x] Seed extraction returns every MVP beverage image target.
- [x] Smoke passes for 2xx/3xx `image/*` responses.
- [x] Smoke fails for non-image content types.
- [x] Smoke fails for bad HTTP status codes.
- [x] Smoke records request errors without crashing the whole report.
- [x] Smoke uses an explicit User-Agent for external image hosts.
- [x] CLI de-duplicates repeated image URLs by default.
- [x] CLI supports seed and active database modes.
- [x] Optional release-gate documentation is updated.

## Rollback

Rollback is code/test/documentation only. Remove
`app.services.beverage_image_url_smoke`, `app.tools.beverage_image_url_smoke`,
the focused tests, and the optional documentation. Existing beverage image
metadata remains unchanged.
