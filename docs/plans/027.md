# Plan 027 - Experience and Budget Evaluation Coverage Gate

## Goal

Raise drink recommendation production confidence by requiring evaluation
coverage across deployed survey experience levels and budget bands.

## Problem

The recommendation evaluation now covers every active beverage category with at
least two fixtures. However, category coverage alone does not prove the service
handles different user maturity levels or budget bands from the deployed
survey-service contract.

An evaluation suite could pass while only testing beginner profiles, or while
missing deployed budget tokens such as `under_30k` or `over_200k`.

## Scope

- Add experience-level coverage metrics to drink evaluation reports.
- Add deployed survey budget-band coverage metrics.
- Add CLI thresholds for both dimensions.
- Add release gate thresholds for:
  - all deployed experience levels
  - at least three fixtures per experience level
  - all deployed budget ranges
  - at least one fixture per deployed budget range
- Adjust evaluation fixtures to include canonical deployed budget bands
  `under_30000` and `over_200000`.

## Non-Goals

- No scoring weight change.
- No mapper change.
- No catalog change.
- No model training.
- No Flutter, gateway, chatbot, or map-service implementation.

## New Metrics

```text
deployed_experience_levels
fixture_experience_level_counts
missing_experience_levels
experience_level_fixture_coverage
minimum_fixtures_per_experience_level
deployed_budget_ranges
fixture_budget_range_counts
missing_deployed_budget_ranges
deployed_budget_range_fixture_coverage
minimum_fixtures_per_deployed_budget_range
```

## Release Gate Thresholds

```text
experience_level_fixture_coverage >= 1.0
minimum_fixtures_per_experience_level >= 3
deployed_budget_range_fixture_coverage >= 1.0
minimum_fixtures_per_deployed_budget_range >= 1
```

## Acceptance Criteria

- [x] evaluation report includes experience-level coverage metrics.
- [x] evaluation report includes deployed budget-band coverage metrics.
- [x] CLI can fail on insufficient scenario coverage.
- [x] release gate enforces scenario coverage.
- [x] focused checks pass.
- [x] full release gate passes.

## Rollback

Rollback is code/data/configuration only. Remove the scenario metrics and CLI
thresholds, and restore the previous fixture budget values if needed.
