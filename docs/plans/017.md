# Plan 017 - Beverage Display Image Metadata

## Goal

Add safe, traceable beverage image metadata so Flutter can display drink
recommendation cards without adding a new database column or changing the
protobuf schema.

This is not recommendation scoring work.

## Scope

- Add category representative image candidates under `data/beverage/`.
- Preserve source URL, license, attribution, and display policy.
- Import image metadata into `beverage_items.metadata_json`.
- Backfill existing active beverage rows through an Alembic data migration.
- Expose `image_url` through recommendation response `metadata`.
- Document Flutter and gateway pass-through behavior.

## Boundary Decision

Canonical ownership:

```text
recommendation-service owns curated MVP beverage catalog display metadata.
```

This service may store display image metadata for beverage catalog cards because
the curated MVP beverage catalog currently belongs to recommendation-service.

This change does not:

- create map/place image ownership
- create venue inventory truth
- use images as ranking evidence
- use RAG or LLM output
- read another service database
- store binary image files

## Source Policy

MVP uses category representative Wikimedia Commons assets with explicit license
metadata.

Reason:

- Product-specific bottle images often have brand/copyright constraints.
- Random search thumbnails are not safe for production display.
- Category representative images are enough to unblock card UI while keeping
  source and license metadata auditable.

Future product packshot work should use:

```text
image_kind = product_packshot
review_status = operator_approved
```

only after operator/legal review.

`beverage_items.metadata_json` receives:

```json
{
  "image_url": "https://commons.wikimedia.org/wiki/Special:FilePath/Glass_of_whisky.jpg",
  "image_alt_text_ko": "위스키 잔 대표 이미지",
  "image_policy_version": "beverage_image_v1",
  "image_kind": "category_representative",
  "image": {
    "policy_version": "beverage_image_v1",
    "image_candidate_id": "bev_image_whiskey_category_representative_001",
    "image_kind": "category_representative",
    "image_url": "https://commons.wikimedia.org/wiki/Special:FilePath/Glass_of_whisky.jpg",
    "alt_text_ko": "위스키 잔 대표 이미지",
    "source_url": "https://commons.wikimedia.org/wiki/File:Glass_of_whisky.jpg",
    "source_type": "wikimedia_commons",
    "license": "Public Domain",
    "license_url": "https://commons.wikimedia.org/wiki/File:Glass_of_whisky.jpg",
    "attribution": "Chris huh / Wikimedia Commons",
    "attribution_required": false,
    "display_policy": "allowed_mvp_display_with_license_metadata",
    "review_status": "source_checked_mvp_seed"
  }
}
```

## API Behavior

`BeverageRecommendation.metadata` includes:

```text
image_url
image_alt_text_ko
image
source.image_url
source.image
```

Flutter can show `metadata.image_url` directly. Attribution details remain
available in `metadata.image`.

## Rollback

Rollback path:

```text
alembic downgrade 0005_scoring_v2
```

The downgrade removes only `beverage_image_v1` metadata keys from
`beverage_items.metadata_json`.
