# Plan 034 - Runtime Route Distance Provider Wiring

## Goal

Wire the venue distance provider through runtime service construction so
recommendation-service can switch from straight-line distance to a future
map-service route client without changing ranking code.

## Problem

Plans 032 and 033 added validated provider output and a map-route adapter base,
but the gRPC serving path still constructs `BeverageRecommendationService`
without a provider. That means runtime deployment has no explicit composition
point for future route-distance integration.

## Scope

- Add map route distance runtime settings.
- Add `create_venue_distance_provider(...)` factory.
- Keep default runtime behavior as `StraightLineVenueDistanceProvider`.
- Allow tests and future server wiring to inject a provider.
- Wire provider through `RecommendationGrpcServicer` and `create_grpc_server`.
- Document staging env behavior.

## Non-Goals

- No map-service proto invention.
- No gRPC/HTTP map-service client implementation.
- No map-service database access.
- No scoring weight change.
- No Flutter, chatbot, gateway, or LLM implementation.

## Runtime Contract

```text
MAP_ROUTE_DISTANCE_ENABLED=false
  -> StraightLineVenueDistanceProvider

MAP_ROUTE_DISTANCE_ENABLED=true with route client
  -> FallbackVenueDistanceProvider(
       primary=MapRouteDistanceProvider(route_client),
       fallback=StraightLineVenueDistanceProvider()
     )

MAP_ROUTE_DISTANCE_ENABLED=true without route client
  -> StraightLineVenueDistanceProvider with warning
```

## Acceptance Criteria

- [x] default runtime provider remains straight-line.
- [x] factory can compose map-route provider with fallback when a client is
  supplied.
- [x] gRPC servicer passes the configured provider to
  `BeverageRecommendationService`.
- [x] docs/env contract include route-distance settings.
- [x] focused checks pass.
- [x] full release gate passes.

## Rollback

Rollback is code/documentation only. Remove the factory/settings/wiring and keep
the existing default provider behavior in `BeverageRecommendationService`.
