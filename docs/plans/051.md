# Plan 051 - Deployed Survey Token Drink Evaluation Coverage

## Goal

Make offline drink recommendation evaluation prove that the current deployed
survey-service token vocabulary produces acceptable drink recommendations.

## Problem

The release gate already had a survey mapper audit and strong drink evaluation
metrics. However, those two checks proved different things:

- mapper audit proved deployed survey tokens map to taste dimensions
- drink evaluation proved reviewed fixtures rank good beverages above bad ones

The missing evidence was the intersection: deployed survey tokens needed to
appear inside drink evaluation fixtures so the normal recommendation scorer
would be tested end-to-end against the current survey-service vocabulary.

## Scope

- Add deployed survey category, category-style token, and flavor keyword
  coverage metrics to the drink evaluation report.
- Add CLI thresholds for those coverage metrics.
- Require full deployed survey token fixture coverage in the release gate.
- Add five evaluation fixtures that use deployed survey-service tokens directly:
  whiskey, wine, cocktail, beer, and cognac.
- Raise the minimum drink evaluation fixture count from 24 to 29.
- Update tests and documentation.

## Non-Goals

- No scoring formula change.
- No DB schema change.
- No proto change.
- No survey-service implementation.
- No model training.
- No direct survey database read.

## Acceptance Criteria

- [x] Evaluation report exposes deployed survey category fixture coverage.
- [x] Evaluation report exposes deployed category-style token fixture coverage.
- [x] Evaluation report exposes deployed flavor keyword fixture coverage.
- [x] Release gate requires all three coverage metrics to be `1.0`.
- [x] Fixture count is at least 29.
- [x] Positive-vs-negative score margins still pass.
- [x] Focused tests pass.
- [x] Full release gate passes.

## Rollback

Rollback is data/test/documentation only. Remove the five deployed-token
fixtures, remove the coverage metrics and CLI thresholds, and return the release
gate minimum fixture count to 24 if necessary.
