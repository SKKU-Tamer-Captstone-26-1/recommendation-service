# Plan 032 - Route Distance Provider Validation Gate

## Goal

Make venue/store/outdoor recommendation distance handling safer before
map-service route distance integration by validating injected
`VenueDistanceProvider` output.

## Problem

The service already supports injected route-aware distance providers and
straight-line fallback. However, a future map-service adapter could return an
invalid `VenueDistanceFeature`, for example:

- negative distance
- missing route distance while `is_route_distance=true`
- non-route result carrying route fields
- confidence outside `[0, 1]`
- blank strategy/source metadata

If recommendation-service accepts those values, venue ranking, logs, Flutter
labels, and chatbot explanations can become misleading.

## Scope

- Add validation for all `VenueDistanceFeature` objects before scoring.
- Treat invalid primary provider output as missing so `FallbackVenueDistanceProvider`
  can use the straight-line fallback.
- Treat invalid final provider output as unroutable so the candidate is not
  ranked.
- Add tests for invalid route provider fallback and invalid non-fallback
  provider exclusion.
- Document the provider output contract.

## Non-Goals

- No map-service implementation.
- No route API client.
- No canonical place DB reads or writes.
- No scoring weight change.
- No Flutter, chatbot, gateway, or LLM implementation.

## Validation Contract

```text
distance_m must be finite and >= 0
strategy/source must be non-empty strings
confidence must be finite and between 0 and 1
is_route_distance must be boolean

if is_route_distance=true:
  route_distance_m must be finite and >= 0
  distance_m must match route_distance_m
  route_duration_seconds, if present, must be >= 0
  straight_line_distance_m, if present, must be finite and >= 0

if is_route_distance=false:
  straight_line_distance_m must be finite and >= 0
  distance_m must match straight_line_distance_m
  route_distance_m must be null
  route_duration_seconds must be null
```

## Acceptance Criteria

- [x] invalid injected route output does not enter venue scoring.
- [x] invalid primary provider output falls back to straight-line distance.
- [x] invalid final provider output excludes the candidate.
- [x] provider output contract is documented.
- [x] focused checks pass.
- [x] full release gate passes.

## Rollback

Rollback is code/documentation only. Remove the distance feature validation and
associated tests. Existing route-ready provider injection remains unchanged.
